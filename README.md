# About this program ~
Editor aiming to allow Berwick Saga hacking in as many aspects as possible, creating a unified tool to allow translated and japanese game editing.

# Features ~
Unitdata editing - All playables, enemies and allies (green and yellow) are now editable, from bases, growths, classes, skills and more.

Unit customization - Swapping name ID, face ID and identity ID of any unit in the game.

Item editor - Editing of all items atributes, effects and flags.

Class editor - Editing bases, growths, caps and flags from any class in the game.

Project import and export - All changes can be exported to a .lep (Lazberian Export Project) file and be easily shared online for import).

English and Japanese support - All features support both the Japanese ISO and English ISO.

# Building ~

This repository provide only the source code, in order for you to build it follow the steps:

1-Download any IDE of your choosing (Microsoft Visual Studio recommended) and install C++ coding dependencies.

2-Install on your system all wxWidgets dependencies and set up a project with a working build.

3-Copy all source files inside the project and set window.cpp as the main.

4-After building it copy all files from the "assets.rar" file inside the same folder the program was build, make sure to keep the folders as is.
